# reports の置き場所

チームが書くファイルは、次の場所とファイル名に置きます。`YYYY-MM` は対象の月、`YYYY-QN` は四半期（例：`2026-Q4`）です。

| 場所 | 書く人 | 中身 |
|---|---|---|
| `reports/analysis/YYYY-MM_集計.md` | budget-analyst | 分類ごとの集計表と、目標との比較 |
| `reports/monthly/YYYY-MM_月次レポート.md` | report-writer | 家族が読む、やさしい月次レポート |
| `reports/reviews/YYYY-QN_点検.md` | policy-reviewer | 四半期の点検と、変更の案 |
| `reports/decisions.md` | リーダー | 大きな提案と家族の決定の記録（1つのファイルに追記していく） |

## ルール

- フォルダがなければ作ってよい。
- 同じ月のファイルを作り直すときは上書きし、冒頭の「データ」の行に作り直した日を書く。
- `decisions.md` は消さずに追記だけする。1件ごとに「日付・提案・理由・見込み・検証する時期・家族の決定」を書き、検証したら「結果（当たった・外れた・まだ分からない）と理由」を書き足す。
- どのファイルにも、カード番号・口座番号、パスワード、勤務先、住所を書かない。
- ここにあるファイルを家族以外に見せるかどうか、どこまで見せるかは家族が決める。
